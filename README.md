# JavaScript Exercises – Orange Coding Academy

## 📌 Description
This repository contains **all JavaScript exercises** from the **Orange Coding Academy** training program, covering concepts from **basic to advanced level**.  
It is designed as a learning resource for students and developers to **practice**, **review**, and **master** JavaScript through structured examples and problem-solving tasks.

The exercises progress gradually, starting from **fundamentals** such as variables and operators, moving to **intermediate topics** like DOM manipulation and events, and ending with **advanced concepts** like ES6 features, asynchronous programming, and API handling.

---

## 🚀 Features
- 📚 **Comprehensive Coverage** – Includes all topics from beginner to advanced.
- 📝 **Well-structured Folders** – Exercises are organized by topic and difficulty level.
- 💻 **Practical Examples** – Hands-on coding tasks to reinforce understanding.
- 🔄 **Incremental Learning Path** – Build skills progressively.
- 🌐 **Real-world Scenarios** – Exercises mimic real project challenges.

---

🎯 Learning Objectives
By completing these exercises, you will:

Understand JavaScript syntax and fundamentals.

Work with functions, objects, arrays, and DOM elements.

Master ES6+ features for modern JavaScript development.

Handle asynchronous programming using callbacks, promises, and async/await.

Interact with APIs and process JSON data.

📌 Notes
These exercises follow the Orange Coding Academy curriculum.

You can attempt exercises in order or skip to specific topics.

Some exercises may require an internet connection for API testing.
